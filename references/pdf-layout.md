# PDF 布局与排版工具

## 默认版式与双语文字

- 每款或已确认的一套搭配一页，`960 × 540 pt`，严格 `16:9`。同页左侧正面、背面、侧面三张独立模特图；右侧实拍正面在上、实拍背面在下。
- 默认中英文结合，页面新增的可见文字**只有完整款号与以下五个视角标签**。保持单行、中文在前、英文在后，用 ` / ` 分隔。

| 模块 | 默认双语标签 | `--language zh` | `--language en` |
|---|---|---|---|
| 模特正面 | 正面 / Front | 正面 | Front |
| 模特背面 | 背面 / Back | 背面 | Back |
| 模特侧面 | 侧面 / Side | 侧面 | Side |
| 实拍正面 | 实拍正面 / Original Front | 实拍正面 | Original Front |
| 实拍背面 | 实拍背面 / Original Back | 实拍背面 | Original Back |

- 不添加系列标题、款名、搭配说明、模块标题、页码、推测提示或提示词。`collection`、旧清单的 `title` / `style_note` 兼容保留，但不在页面显示。实拍原图中本来就存在的款号、标签和文字属于原始图像内容，不伪造、重绘或移除；页面文字白名单检查只针对 PDF 排版新增的文字。
- `side_inferred` 缺省为 `true`，如实留在清单和验收记录中，不在极简页面打印。只有充分侧面实拍依据时才设为 `false`；不因页面省略说明而把推测结构当成事实。
- 图像区域左约 73%、右约 27%。三张模特图同列宽、同基线；右侧正背图上下对应。套装的每个原图视角支持多张实拍并排展示，通常为上装与下装两张。
- 白底、黑灰文字、0.4 pt 浅灰外框、顶部细线与一条竖向分隔线。留白充足，不添加阴影、渐变、厚卡片、装饰标志或城市元素。
- 图像统一等比 `contain`；不拉伸、不为填满画框裁掉头、鞋或服装轮廓。源照片本身已经缺失的内容无法由排版恢复。按实际置入尺寸最多 300 ppi 导出，透明图保留透明通道，其余照片使用高质量 JPEG 嵌入；不重绘、不磨皮、不调色、不额外叠加噪声，原始素材不改写。
- 字号默认款号 12 pt、标签 8 pt。过长款号可缩至 9 pt，仍放不下则报错；禁止截断或改写款号。中文与英文使用同一套可嵌入的 TrueType 字体，缺字形时报错。

## 输入清单

清单是 UTF-8 JSON，接受 BOM。相对图像路径以**清单所在目录**为基准，Windows 路径建议用 `/`。路径字符串按原样解析，保留合法文件名中的连续空格，不静默 trim 或合并空白。款号保留内部连续空格；首尾空白、换行、制表和控制字符会明确报错，由输入方修正，不由排版程序擅自改号。必需字段为 `items` 及每款的 `id`、三个 `model` 视角和两个 `source` 视角；缺图、坏图、空列表、重复款号直接报错，不借用其他款式，不补占位图。

```json
{
  "collection": "2027 AUTUMN / WINTER",
  "items": [
    {
      "id": "2027AW-065",
      "model": {
        "front": "approved/2027AW-065-front.png",
        "back": "approved/2027AW-065-back.png",
        "side": "approved/2027AW-065-side.png"
      },
      "source": {
        "front": "originals/2027AW-065-front.jpg",
        "back": "originals/2027AW-065-back.jpg"
      },
      "side_inferred": true
    }
  ]
}
```

套装可将每个 `source` 视角改为非空数组，上下装顺序在正背两组保持一致。款号可将真实的上、下装款号用 ` / ` 并列，不凭空编造整套款号。

```json
"source": {
  "front": ["originals/top-front.jpg", "originals/bottom-front.jpg"],
  "back": ["originals/top-back.jpg", "originals/bottom-back.jpg"]
}
```

字符串路径也可替换为 `{ "path": "originals/contact-sheet.jpg", "crop": [0, 0, 0.5, 1] }`。`crop` 是归一化 `[x, y, width, height]`，以 EXIF 方向校正后图像左上角为原点；仅用于已检查的拼版原图拆分或去除空边，不触碰服装、鞋或头部。排版通过 PDF 视窗限制显示区域，原始文件仍只读。上述数值只是格式示例，不可盲用；必须逐图核对边界、前后顺序及内容。一个模特图文件只能对应一个角度，不能以同一张正面图冒充背面或侧面。

## 运行与检查

先定位本机 Python 和 `reportlab`、`Pillow`、`pypdf`，优先使用当前环境提供的依赖，不把某台电脑的运行时路径写入 skill。首次执行 PDF 创作命令前，遵守当前 PDF skill 的标记要求；只检查输入不构成 PDF 创作。

```powershell
# $pythonPath 是已定位的 Python 可执行文件绝对路径。
& $pythonPath "<skill目录>/scripts/build_lookbook.py" "<批次目录>/manifest.json" "<批次目录>/lookbook.pdf" --check-only
& $pythonPath "<skill目录>/scripts/build_lookbook.py" "<批次目录>/manifest.json" "<批次目录>/lookbook.pdf"
```

可选参数：

- `--language bilingual|zh|en`：默认 `bilingual`，即中英文结合。仅在用户明确改变偏好时切换单语。
- `--font "C:/Windows/Fonts/Deng.ttf"` 或环境变量 `LOOKBOOK_FONT`：指定可嵌入字体。默认探测微软雅黑、等线等及常见 macOS/Linux 字体。要求 TrueType 轮廓，TTC 使用第 0 个字面；只检查实际显示的款号和所选语言标签所需字形。
- `--check-only`：检查必需视角、路径、图片可解码性、视窗、款号宽度、字体覆盖，输出实际输入路径与文字白名单，不写 PDF。它不能确认图像中服装和角度正确。
- `--overwrite`：显式允许覆盖。默认拒绝同名输出；覆盖时先在内存中生成和校验完整 PDF，再在目标目录临时写入并原子替换，失败不损坏旧 PDF。

成功输出 JSON，包括页数、`960 × 540 pt`、`16:9`、语言、字体、实际输入图片和每页文字白名单。写入前用 pypdf 检查页数、尺寸、字体嵌入，并逐行核对抽取文字必须严格等于该页款号加五个指定视角标签；出现多余标题或推测标签即失败。失败退出码为 2。

## 导出后验收

用 Poppler `pdftoppm -png -r 120 lookbook.pdf previews/page` 渲染每页并逐页看图：衣服、头部与鞋完整，三视角一致，侧面确实是侧面，实拍与款号对应，中英文清晰，细框不压图，无重叠与溢出。放大核验样衣绒毛、反光、五金、缝线与三视图的一致性；文字和结构检查不能代替视觉验收。

交付 PDF 和三张独立、已验收的模特图；提示词、输入清单、内部验收记录放在配套文件中，不挤进展示页。没有可用成图时不制作假成品。排版回归测试可复用已验收素材，但放进独立测试目录并以文件名或配套测试说明明确其用途，不污染正式交付；占位图仅可用于另行标注的几何排版测试，不能作为成图交付。
