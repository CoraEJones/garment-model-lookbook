# 材质保真与自然窗光配方

## 样衣真实性：独立于人像审美

商品实拍定义服装。风格照片仅定义人物、摄影语言；一张风格图里的亮皮、印花、光泽或款式不能覆盖样衣依据。

为每款记录以下观察，正背共用：

| 字段 | 观察内容 |
| --- | --- |
| 表面与尺度 | 光滑/短绒/长绒/针织/粗织，绒毛方向、织纹大小、颗粒疏密 |
| 图案 | 有无真实印花、提花、压纹，尺度、疏密、方向、位置及拼接关系；区分图案与绒毛顺逆、光照形成的明暗 |
| 光泽 | 哑光/微光/缎光/镜面；高光宽窄、强弱、出现位置、折痕中的变化 |
| 体积与受力 | 厚薄外观、挺度、垂坠、弯肘与腰部折痕、重力方向 |
| 颜色 | 主色与拼色、冷暖和明度关系，多张原图支持程度 |
| 禁止漂移 | 本款最易被误改的具体材质、图案、五金和结构 |

不同材质使用不同约束，不能把“所有衣服都哑光”写进共用提示：

- 无图案短绒/绒面：保留大块柔和不规则顺逆绒明暗，不转成卷草、裂纹、印花或压花。颗粒不是花纹。
- 光面皮革：保留原图反射强度和自然折痕，不因为脸要哑光就消除皮革反光。
- 缎面或涂层：保留随褶皱移动的高光带，避免整体死白、灰哑或改成针织。
- 毛织/粗纺：保留纤维及织纹的相对尺度，不统一加长绒毛或锐化成刺状。
- 亮片/金属点：按原图控制大小密度；无法判断成分时只描述可见反光点。

图像噪声应是成像现象，不是物体表面新增结构。增加肤质细节不得同时让夹克、裤子、背景和地面长出纹路。材质失真是拒收条件，不靠后期灰度、降饱和或加噪遮掩。

## 自动搭配

根据主衣轮廓、颜色、视觉重量和季节感补齐穿搭，默认通勤休闲。尽量让主衣的轮廓与材质可读：

- 宽窄、长短、轻重协调；新增外套不得遮住用户主衣。
- 使用主色、辅助色和少量强调色，允许同色系或克制对比；不把所有款都固定为米白棕。
- 鞋型与裤裙轮廓连贯，饰品少且不遮袋口、门襟或腰侧；无需要时不强加包袋。
- 多件用户样衣可作为套装处理；其真实颜色和材质均须锁定。
- 颜色由未校色照片推断时，不声称获得精确商品色卡或购买品牌。

## 默认视觉配方：natural-window-v3

以已完成并经过视觉检查的单款自然窗光三视图为基础，固定当前人物、发肤与摄影设定。灰背景不等于人工多灯棚拍：默认是窗边的极简灰色室内环境。用户要求其他人物时替换人物卡，样衣保真和同款一致始终有效。

| 模块 | 可复用设定 | 避免 |
| --- | --- | --- |
| 人物 | 年轻成年欧美女性，健康偏修长比例，轻松自然的面部肌肉 | 未成年感、夸张长腿、过度瘦削、僵硬摆拍 |
| 头发 | 深栗棕中长发近中分，脑后随意松散挽成低发髻，头顶蓬松；不规则额前长碎发和沿脸颊、颈部散落的鬓发 | 默认沿用旧短波波头、整齐发髻、重复S形高光带、环状飞发光晕、逐根刻线 |
| 皮肤 | 浅肤色带自然粉调，轻薄裸妆，双颊轻红、眼下淡影；保留皮纹与额头/鼻梁的柔和自然光泽 | 刻意通透发光、整脸消成粉灰、全脸油光、蜡质、强磨皮、均匀毛孔噪点 |
| 个体细节 | 当前人物使用鼻旁一颗细小深色痣、自然唇纹与眉毛方向差异，按人物卡固定 | 继续强加大片雀斑、痣位随视图翻转、深痘坑、浓重眼袋、为自然感制造衰老 |
| 眼睛与表情 | 眼睑和嘴角细微自然差异，正常柔和眼部反射、非纯白眼白，平静或轻松表情 | “眼神发光”“眼睛极致锐利”、玻璃虹膜、强对称美容表情 |
| 环境 | 极简室内中性深灰背景与平整灰地面，窗可在画外；保留房间自然亮暗落差 | 城市元素、复杂道具、到处亮度一致、地毯/浮雕纹、虫状颗粒 |
| 光线 | 一个固定窗位的自然日光，默认镜头左前方；只有房间本身的弱环境反射，保留鼻侧、下颌和接触阴影 | 额外棚灯、四面补光、美容透光、硬轮廓灯、HDR提亮暗部、压黑样衣、橙青滤镜 |
| 成像 | 自然透视、柔和反差与轻微光学柔化，适量细胶片颗粒观感；真实皮纹和衣物细节仍可读 | HDR、锐化白边、商业渲染式极锐、粗颗粒蒙层、用噪点替代肤质、磨糊衣料 |

镜头词仅表达视觉意图，不是实际相机元数据。参考截图/JPEG中的颗粒来源可能是相机、胶片、压缩或后期，不能据此断定ISO或器材。皮肤不是光泽完全为零；保留少量与光向一致的真实反射。

全身图中微小毛孔、汗毛只需符合观看尺度，不能强行呈现微距细节。不同时堆叠“8K、每根汗毛极清晰、强颗粒、浅景深、全画面锐利”等冲突目标。深度主要分离背景，领口、衣摆、裤脚和鞋仍可核对。

## 当前人物锁定卡

- 年轻成年女性，健康偏修长比例；椭圆偏修长脸型、纤细鼻梁、自然浓密的棕色眉毛、灰棕色眼睛、裸玫瑰色嘴唇。
- 浅肤色带自然粉调，双颊轻微泛红，眼下保留淡淡阴影。轻薄裸妆，皮纹清楚但符合全身景别；额头和鼻梁保留随窗光变化的柔和反光。不要要求皮肤反光完全为零。
- 正面、非镜像图中，画面右侧鼻旁有一颗细小深色痣，即人物自身左侧鼻旁。将其固定为人物左侧解剖位置。转向后按可见性显示：右脸朝镜头时通常看不到它，不能为每个角度都出现而搬到另一侧。发丝遮挡时也允许自然遮住。
- 深栗棕色中长发，接近中分，脑后随意松散挽起，头顶蓬松、略凌乱。额前轻薄、不规则长碎发，一缕弯曲发丝从眉间附近垂至鼻侧；两侧鬓发沿脸颊与颈部散落，部分到衣领，细碎飞发自然可见。背面应呈现真实松挽发结构；发丝不可盖住样衣关键领型、拼缝或图案。
- 这是当前默认人物预设；没有新的指定时沿用这些特征，不自动退回旧短发人物。用户仍允许不同款换人，可在同一审美范围内建立不同人物卡；新指定的人物要求优先，同款三个角度始终保持同一人。
- “spontaneous human interaction”在单人三视图中解释为自然重心、手臂状态和松弛反应；不据此添加第二个人、互动道具或遮挡服装的动作。

## 同款三视图与空间关系

- 同款固定人物锚点、发色长度、妆面、衣鞋饰、扣合/抽绳/扎衣状态。
- 在正面基准验收前选定机位、窗位与基础曝光；锁定后背景、窗位、相机距离和高度固定，仅人物按规定视角转身。脸与面料的受光相应变化，不为各角度移动相机追光或加面部补光。可合理调整曝光保持样衣可读，但不改变衣色、不把正背侧改为三分之二侧面、不把暗部统一拉成HDR。
- 正面前片主要朝镜头，重心可轻偏；背面完整后片朝镜头，头发不遮关键拼缝；侧面接近90°，手臂不遮侧部结构。
- 竖幅2:3为默认生成画幅意图，全身、完整头鞋、适量留白。记录工具真实输出尺寸，排版不强行拉伸。
- 背图不得复制前门襟/前袋；没有侧面实拍时只保守连接可见前后结构。

## 参考与修正的有效用法

用户给一批真人图时先做总览，再放大可读的代表图，区分自然皮肤、精修妆面、硬光、柔光与低清压缩。用具体可见事实选择参考；不要把所有图的冲突特征全部混进提示。

一次只修具体问题，并保持衣料约束。反复沿用失真生成图可能累积材质卷花、地面伪纹和人工碎发。出现这类漂移时，回到商品实拍及有效发肤参考重新建立正面，比继续添加“texture/pores/grain”更可控。重建后要重新生成配套角度，不能混用旧人物或旧光场。
